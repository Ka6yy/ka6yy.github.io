# ka6yy (localhost) — портфолио

Статический мини-сайт в стиле GitHub-профиля: «мел по чёрному», рукописные заголовки, `>_`.
Без сборки и зависимостей — HTML + CSS + ванильный JS, поэтому бесплатно живёт на GitHub Pages.

- Карточки работ с фильтрами (веб, приложения, AI/ML, безопасность, данные, видео).
- Окно работы с галереей скриншотов, «что сделано», стеком и ссылками; у каждой работы своя ссылка вида `#/w/spyde`.
- RU / EN и тёмная («мел») / светлая («карандаш») темы — переключатели в шапке, выбор запоминается.
- Адаптив до телефона, клавиатура (Esc, ← →), `prefers-reduced-motion`.

## Как добавить или поменять работу

Всё содержимое — в одном файле **`works.js`**. Код сайта трогать не нужно.

1. Скопируйте шаблон в самом низу `works.js` и заполните поля.
2. Картинки положите в `assets/works/<slug>/` и пропишите пути в `cover` (обложка, лучше 16:10) и `shots` (галерея).
   Подойдут `webp`, `png`, `jpg`. Без `cover` карточка нарисует меловую обложку по полю `icon`.
3. Любой текст — строка (одна на оба языка) или `{ ru: '…', en: '…' }`.
4. Для командной работы вместо `points` заполните `mine` (что сделал я), `team` (что делала команда),
   `contrib` (строка про вклад: коммиты, PR) и `badge` (короткая подпись на карточке).

Профиль, контакты, цифры статистики и стек — там же, в `window.PROFILE`.

## Посмотреть локально

Достаточно открыть `index.html` двойным кликом. Или через сервер:

```bash
python3 -m http.server 8790
```

и открыть http://localhost:8790.

## Где живёт

Сайт опубликован на GitHub Pages: **https://ka6yy.github.io** (репозиторий `Ka6yy/ka6yy.github.io`, ветка `main`, корень).
Обновление — обычный `git push`, через минуту-две изменения на сайте.

Заменили картинку под тем же именем — поменяйте `window.ASSET_VERSION` в начале `works.js`,
иначе браузеры какое-то время будут показывать старую из кэша.

Свой домен: положите в корень файл `CNAME` с доменом (например, `ka6yy.dev`), у регистратора
заведите `CNAME`-запись `www → ka6yy.github.io` или `A`-записи корня на адреса GitHub Pages,
затем в настройках Pages включите HTTPS. Адреса в `og:image` / `og:url` / `canonical` в `index.html` поменяйте на новый домен.

## Что где лежит

```
index.html              каркас страницы
works.js                ← всё содержимое: профиль, работы, категории
assets/css/style.css    стили и темы (токены в :root)
assets/js/app.js        отрисовка, фильтры, окно работы, язык и тема
assets/works/<slug>/    скриншоты работ
assets/img/             favicon и картинка для превью ссылки (og.png)
.nojekyll               чтобы GitHub Pages отдавал файлы как есть
```

## Что на скриншотах

Скриншоты LexFiles (веб, десктоп, мобилка) сняты с локального тестового стенда с вымышленными данными:
дело ООО «Северный причал», пользователь «Алексей Морозов». CRM (свой проект) снята на отдельной демо-базе
(«Анна Иванова», «Пётр Смирнов»), лендинг — с публичного сайта lexfiles.online.
Если добавляете новые скриншоты, проверьте, что на них нет реальных клиентов, ФИО и почты.
